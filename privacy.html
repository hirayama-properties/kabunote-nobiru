プライバシーポリシー

最終更新日: 2026年8月4日

1. 基本方針

Hirayama Properties K.K.（以下「当社」）は、アプリ「株ノートNOBIRU」（以下「本アプリ」）における利用者のプライバシーを尊重し、以下の方針でデータを取り扱います。

2. アカウント登録について

本アプリはアカウント登録・ログインを必要としません。氏名・メールアドレス・パスワード等の登録情報を当社が収集することはありません。

3. 取引データの保存場所

売買記録・投資根拠タグ・感情タグ・損益データ等の取引データは、利用者の端末内にのみ保存されます。当社が管理するサーバーに取引データが送信・保存されることはありません。

4. 外部サービスとの連携（任意）

利用者が任意でGoogleスプレッドシートまたはNotionとの同期機能を有効にした場合、取引データは利用者自身のGoogleアカウントまたはNotionアカウントに直接保存されます。この通信は利用者の端末と各サービスとの間で行われ、当社のサーバーを経由しません。同期を無効にすればこの機能は動作しません。

5. Googleユーザーデータの取扱いについて

本アプリのGoogleスプレッドシート連携機能に関し、Google API Services User Data Policy（Limited Use要件を含む）に基づき、以下のとおり取扱いを明示します。

■ アクセスするデータ
Googleスプレッドシート連携を有効にした場合、当社が取得するのは、利用者が指定したスプレッドシートへ取引記録を追記するためのアクセストークンのみです。利用者の既存のスプレッドシートの内容を読み取ることはありません。

■ データの利用目的
取得したアクセストークンは、本アプリに入力された取引記録を、利用者自身が指定したGoogleスプレッドシートへ同期する目的にのみ、利用者の端末上で使用します。

■ データの保存場所
アクセストークンは当社のサーバーには一切送信・保存されず、利用者の端末内にのみ保存されます。

■ データの第三者提供・共有
Googleスプレッドシート連携により取得したデータ（アクセストークンを含む）を第三者に提供・共有・販売することはありません。広告目的での利用も一切行いません。

■ データの保持・削除
アクセストークンは利用者の端末内に保存されるため、アプリのデータ削除、またはGoogleアカウントの設定からアクセス権を取り消す操作により、いつでも削除できます。

■ Limited Use遵守表明
当社によるGoogle APIから取得したユーザーデータの利用は、Google User Data Policy（Limited Use要件を含む）を遵守します。

6. 課金・決済情報の取扱い

プレミアムプランのお申し込みは、App Store（Apple）またはGoogle Playの決済システムを通じて行われます。クレジットカード番号等の決済情報を当社が直接取得・保存することはなく、Apple社・Google社がそれぞれの規定に基づき処理します。

当社は、購読状況の管理のためにRevenueCat, Inc.が提供するサブスクリプション管理サービスを利用します。RevenueCatは購読の開始・更新・解約といった購入履歴の情報を処理しますが、これは本アプリの課金機能を提供する目的にのみ利用され、広告目的での利用や第三者への販売は行いません。

7. アプリストアが取得する情報

App Store／Google Playでのインストール・課金処理に伴い、Apple社・Google社がそれぞれのプライバシーポリシーに基づき情報を取得する場合があります。これらは各社のポリシーに従うものであり、当社が直接収集するものではありません。

8. データの削除

本アプリをアンインストールすると、端末内に保存された取引データは削除されます。外部サービスに同期済みのデータは、利用者自身がそれぞれのサービス上で管理・削除してください。

9. お問い合わせ

本ポリシーに関するお問い合わせは お問い合わせフォーム よりご連絡ください。
